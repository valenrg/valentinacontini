03 / APPLICATION

One rulebook. Multiple personalities.

Core, CT LAB and Collision Lab use the same underlying layout, typography and accessible interaction logic; accent is chosen by expression and surface.

Use in your work: start with tokens.json as the source, tokens.css and components/bundle.css as the implementation, and voice.md for written language. Detailed integration instructions are in INTEGRATION.md. All component API docs are local.
VALENTINA CONTINI / BRAND SYSTEM

This manual contains no external runtime dependencies and no font files. Glacial Indifference is the preferred display face; your device uses the fallback when it is unavailable.
