# Voice and microcopy

Ready-to-use words for the small parts of a page, in Valentina's voice: first person, short, specific, a little wit, never a slogan. Copy these, then adjust the facts. Text in [brackets] is a gap to fill with something true; never ship it empty or guessed.

## Rules of thumb

- Say what happens, then stop. One idea per line.
- Name the thing: the project, the sensor, the file. "Open field file", not "Learn more".
- Write in sentence case. Uppercase comes from the style (`eyebrow`, `meta`, `button-label`, display titles), never from typing capitals.
- Kickers and meta lines use a spaced slash: "Research / 01", "Personal portfolio / selected work".
- Wit goes in the second half of a line, after the useful part. If a joke would hide the instruction, cut the joke.
- No exclamation marks in interface text. No emoji.

## Actions

Verb first, object when it adds meaning. These come from the site and manual:

| Use | Label |
|---|---|
| Go to an overview of a project or experiment | Explore project |
| Go to the technical record | Open field file |
| Go to a set of work | View selected work |
| Open a document or tool | Open |
| Get a file | Download |
| See the code or build log | See build |
| Start a conversation | Say hello |
| Check where something came from | Read the sources |
| Return to the top of a long page | Back to top ↑ |
| Close a dialog | Close |

- Never "Learn more", "Click here", "Discover", "Get started" or "Submit".
- A link that opens a new tab says so in its accessible name: "Source on GitHub (opens in a new tab)".

## Status lines

Use the five `Status` words exactly. When a sentence needs more, add the fact, not an adjective:

- Do: "Hardware ordered. Nothing to report until the parts arrive."
- Do: "In progress: sensors tested, actuator not built yet."
- Don't: "Coming soon", "Beta", "Launching shortly", "Almost there".

## Describing a project

Formula: what it is, how it works, what it is not.

- Do: "EEG-driven generative wearable. It transforms EEG-derived artistic variables, not thoughts or diagnoses."
- Don't: "A revolutionary wearable that reads your mind and turns emotions into art."

Keep concept, experiment and deployed work apart in the wording: "a concept for", "an experiment testing", "a working [object] used in [place]".

## Empty states

Say what is empty and what to do next.

- No results from filters: "Nothing matches these filters. Drop one, or show everything."
- No field files yet: "No field files yet. The first one goes up when there's something real to report."
- Empty list in an instrument: "No pairs selected. Pick two technologies to compare."

## Errors

State the problem, then the fix, with an example. The `Field` component adds "Error:" before the message.

- Format: "Use six hex digits, for example #F7F5F2."
- Missing input: "Add your email so I can reply."
- Message failed to send: "That didn't send. Your text is still here. Try again, or write to hello@valentinacontini.eu."
- Data failed to load: "The instrument couldn't load its data. Reload the page to try again."
- Never "Oops!", "Something went wrong" on its own, or "Invalid input".

## Confirmations and loading

- Sent: "Sent. Thanks for writing."
- Contact line: "Say hello: hello@valentinacontini.eu". This is the only contact address; use it as a `mailto:` link with the address visible.
- Copied: "Copied #6D23C8."
- Loading: "Loading the data." Say what is loading; no "Hang tight".

## 404 page

- Kicker: "Error / 404"
- Headline (one accented phrase): "Nothing here. *Not even* a prototype."
- Lead: "The link is old or mistyped. The work is still where it was."
- Action: "View selected work"

## Bio lines

Built from lines in the brand files. The brand stands on its own, independent of any job: bios describe what Valentina investigates and builds, never a current job title or employer. Where an event organiser asks for an affiliation, give it in their programme, not on the site or in these lines. Add credentials yourself; none are invented here.

- One line: "I research the future. Then I build bits of it."
- First person, short: "I investigate emerging technologies, turn questions into experiments, and build prototypes to find out what survives contact with reality."
- Third person, for a speaker page or programme: "Valentina Contini investigates emerging technologies, turns questions into experiments and builds prototypes to find out what survives contact with reality. [One concrete project, with what it found.]"

## Words

| Use | Avoid |
|---|---|
| investigate, test, build, prototype, measure, find out | unlock, revolutionise, transform (as a boast) |
| experiment, field file, concept, prototype, deployed | solution, offering, ecosystem |
| the specific technology: EEG, BLE, actuator, sensor | cutting-edge, next-generation, state-of-the-art |
| what it found, what failed, what's next | seamless, game-changing, innovative |

The first four avoid words come from the brand guidelines; "leverage", "harness the power of", "empower" and "synergy" are added here as the same kind of filler.

## Do and don't

| Do | Don't |
|---|---|
| I research the future. Then I build bits of it. | Unlock transformative innovation with cutting-edge solutions. |
| Sensors tested; actuator still planned. | A groundbreaking kinetic textile, coming soon. |
| Open field file | Learn more |
| Nothing matches these filters. Drop one, or show everything. | Oops! No results found. |
